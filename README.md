# ☕ Coffee Shop Sales Analysis Dashboard | Power BI

## 📌 Project Overview

This project presents an interactive **Coffee Shop Sales Dashboard** built using Microsoft Power BI. It analyzes coffee shop sales data to identify sales trends, compare store performance, and understand product category performance.

The dashboard uses a coffee-themed design with KPI cards, charts, and interactive slicers to make business insights easy to understand.

## 🎯 Project Objectives

- Analyze overall sales performance.
- Track total sales, transactions, and quantity sold.
- Compare sales across different store locations.
- Understand sales distribution across product categories.
- Identify sales trends by month and hour.
- Enable interactive data exploration using slicers.

## 🛠️ Tools & Technologies

- **Microsoft Power BI Desktop** — Dashboard development and visualization
- **Power Query** — Data preparation and transformation
- **DAX** — Calculated measures and data analysis
- **Microsoft Excel / CSV** — Dataset source, if applicable

## 📊 Dashboard Features

### 1. Key Performance Indicators (KPIs)

- **Total Sales:** Overall revenue generated.
- **Total Transactions:** Number of unique transactions.
- **Total Quantity Sold:** Total number of items sold.
- **Total Products:** Number of distinct product IDs in the dataset.

### 2. Sales Analysis

- **Sales by Month:** Analyze monthly sales trends.
- **Sales by Store Location:** Compare sales across Astoria, Hell's Kitchen, and Lower Manhattan.
- **Sales by Product Category:** Understand the contribution of different product categories.
- **Sales by Hour:** Identify sales patterns throughout the day.

### 3. Interactive Filters

The dashboard includes slicers for:

- Store Location
- Month
- Product Category
- Day Name

These filters help users explore sales performance across different business dimensions.

## 📁 Dataset Information

The dataset contains coffee shop transaction records, including fields such as:

- `transaction_id`
- `transaction_date`
- `transaction_time`
- `transaction_qty`
- `store_id`
- `store_location`
- `product_id`
- `unit_price`
- `product_category`
- `product_type`
- `product_detail`

Additional columns, including sales amount, month, hour, and day name, are used for analysis.

## 🚀 How to Use

1. Clone or download this repository.
2. Install [Microsoft Power BI Desktop](https://powerbi.microsoft.com/desktop/).
3. Open the `.pbix` Power BI report file.
4. If the dataset is included, update its file path if required.
5. Refresh the data if prompted.
6. Use the slicers to interact with the dashboard.
